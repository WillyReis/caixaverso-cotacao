# ADR-001: Stack do projeto — Java 25 e Quarkus 3.40 LTS

- **Status:** Aceito
- **Data:** 2026-11-09
- **Atualizado:** 2026-11-13
- **Responsáveis:** time/caixa

## Contexto

O Caixaverso Cotação precisa de uma stack definida para orientar o desenvolvimento e produzir builds reproduzíveis. O grupo aprovou Java 25 e Quarkus 3.40 LTS para este projeto, alinhando-se à diretriz corporativa informada ao grupo.

Esta decisão se aplica ao Caixaverso Cotação. Ela não estabelece uma política de migração para outras aplicações. A referência documental específica da diretriz corporativa não está identificada neste repositório e deve ser registrada quando estiver disponível.

## Decisão

- Adotar **Java 25 (JDK 25)** para o desenvolvimento do Caixaverso Cotação.
- Adotar **Quarkus 3.40 LTS** como framework do projeto.
- Limitar o escopo desta decisão a este projeto; a atualização de aplicações existentes está fora deste ADR.
- Definir a versão do Maven ao preparar a implementação, mantendo-a fixada na configuração do build.
- Tratar persistência, API interna e topologia nos documentos arquiteturais correspondentes; este ADR não os decide.

## Consequências

- **Benefícios:** fornece uma base tecnológica comum e explícita para desenvolvimento, build e testes do projeto.
- **Custos e riscos:** dependências, plugins de build, ambiente de execução e pipeline de testes precisam ser compatíveis com as versões escolhidas.
- **Acompanhamento:** fixar e validar as versões efetivamente usadas no build. Registrar a fonte corporativa específica quando identificada, sem ampliar o escopo desta decisão.
