# ADR-001: Adoção do padrão corporativo Java 25 e Quarkus 3.40 LTS
 
- **Status:** Aceito
- **Data:** 2026-11-09
- **Responsáveis:** time/caixa
 
## Contexto
A Caixa definiu Java 25 e Quarkus 3.40 LTS como versões oficiais para desenvolvimento de novos projetos e evoluções. O uso do Quarkus 3.33 será descontinuado, e as aplicações existentes nessa versão deverão ser atualizadas.
 
## Decisão
Adotar o padrão corporativo **Java 25 + Quarkus 3.40 LTS**.
 
- Novos desenvolvimentos e evoluções devem utilizar Java 25.
- Novos projetos e novas implementações devem utilizar Quarkus 3.40 LTS;
- Aplicações existentes em Quarkus 3.33 devem ser atualizadas conforme o planejamento de evolução tecnológica.
 
## Consequências
- **Benefícios:** Alinhamento com o padrão tecnológico oficial da Caixa.
- **Custos e riscos:** As aplicações existentes em Quarkus 3.33 exigirão planejamento e execução de atualização.
