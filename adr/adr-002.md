# ADR-002: Ingestão agendada com persistência local

- **Status:** Aceito
- **Data:** 2026-11-10
- **Responsáveis:** Grupo 2

## Contexto
O Caixaverso Cotação fornece históricos de cotações obtidos da API do BACEN. Para o escopo inicial, serão armazenados os valores de compra e venda de dólar (USD) e euro (EUR) dos boletins de abertura e encerramento, sem os boletins intermediários.

A PTAX é a taxa de câmbio de referência do real em relação ao dólar publicada pelo BACEN. O fechamento corresponde à média das taxas apuradas nas quatro consultas diárias. O BACEN também publica cotações de outras moedas, como o euro.

## Decisão
Adotar ingestão **assíncrona agendada**, com persistência local em **H2**. A escolha de H2 substitui a referência a PostgreSQL da versão provisória deste ADR, conforme decisão do grupo registrada na Constituição do Projeto.

- O componente APP (job) executará rotinas agendadas alinhadas à publicação dos boletins do BACEN, buscando as cotações e gravando os dados no H2. As novas tentativas e a recuperação de pendências seguirão as regras de negócio aprovadas.
- O componente APP (API) atuará somente como leitor dos dados de cotação armazenados, atendendo às consultas dos usuários a partir do banco local.
- Não haverá tráfego síncrono do fluxo do usuário para a API do BACEN. A ausência de dados no banco não provocará coleta sob demanda.
- A topologia de processos e containers permanece pendente de definição. Esta decisão estabelece as responsabilidades dos componentes, sem fixar sua implantação.

## Consequências
- **Benefícios:** As consultas dos usuários ficam separadas da coleta no BACEN e são atendidas a partir dos dados persistidos localmente.
- **Custos e riscos:** O histórico disponível depende das execuções do job, exigindo controle de pendências e prevenção de duplicidade.
- **Contrato da API:** A API deverá comunicar dados ausentes ou parciais por um campo de disponibilidade. O nome, os valores e o formato desse campo permanecem pendentes de definição no contrato da API.
