# ADR-002 -- Ingestão agendada com persistência local

Status: Aceito pelo grupo.
Contexto: o Caixaverso Cotação fornece históricos de cotações obtidos da API do BACEN. Para o escopo inicial, serão armazenados os valores de compra e venda de dólar e euro dos boletins de abertura e encerramento, sem os boletins intermediários.
O que é PTAX: é a taxa de câmbio de referência do real em relação ao dólar publicada pelo BACEN. O fechamento corresponde à média das taxas apuradas nas quatro consultas diárias. O BACEN também publica cotações de outras moedas, como o euro. Referência do BACEN sobre a PTAX.
Decisão: adotar ingestão assíncrona agendada, com persistência local em PostgreSQL.
1.	O container APP (job) executará rotinas agendadas alinhadas à publicação dos boletins do BACEN, buscando as cotações e gravando os dados no PostgreSQL. As novas tentativas e a recuperação de pendências seguirão a política descrita no item 1.
2.	O container APP (API) atuará somente como leitor dos dados de cotação armazenados, atendendo às consultas dos usuários a partir do banco local.
3.	Não haverá tráfego síncrono do fluxo do usuário para a API do BACEN. A ausência de dados no banco não provocará coleta sob demanda.
Consequências: as consultas dos usuários ficam separadas da coleta no BACEN. Em contrapartida, o histórico disponível depende das execuções do job, exigindo controle de pendências e prevenção de duplicidade. A API deverá comunicar dados ausentes ou parciais pelo campo de disponibilidade previsto no contrato, cujo detalhamento fica para depois.
